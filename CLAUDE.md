# CLAUDE.md

Guidance for AI agents working in this repository.

## Git commits

- Do **not** add a `Co-Authored-By` trailer for Claude / Claude Code, and do not list
  Claude or any AI tool as a contributor.
- Do **not** mention Claude Code (or any AI tool) in commit messages or PR descriptions.
- Write commit messages in the project's normal voice, describing the change only.

## Planning artifacts

- `docs/superpowers/specs/` and `docs/superpowers/plans/` hold local-only working docs
  (design specs and implementation plans). They are gitignored — do **not** commit them.
